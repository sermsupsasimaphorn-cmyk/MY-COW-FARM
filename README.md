# MY COW FARM

## การเริ่มใช้งาน

ต้องติดตั้ง Node.js 20 ขึ้นไป จากนั้นเปิด PowerShell ในโฟลเดอร์โครงการแล้วรัน:

```powershell
npm install
npm start
```

เปิดเว็บที่ `http://127.0.0.1:3000` การสมัครสมาชิกและเซสชันเข้าสู่ระบบจะถูกจัดเก็บใน SQLite ที่ `data/farm.sqlite` โดยเซสชันจะจำการเข้าสู่ระบบเป็นเวลา 30 วัน

บัญชีเดิมที่เคยบันทึกในเบราว์เซอร์จะถูกย้ายเข้า SQLite อัตโนมัติเมื่อเปิดเว็บผ่านเซิร์ฟเวอร์ครั้งแรก ข้อมูลวัว อาหาร และรายการอื่นของฟาร์มยังจัดเก็บในเบราว์เซอร์เครื่องเดิมตามระบบเดิม

ห้ามเปิด `index.html` โดยตรง เพราะการสมัครสมาชิกและการเข้าสู่ระบบต้องเชื่อมต่อกับเซิร์ฟเวอร์

## เผยแพร่เว็บบน Render

ไฟล์ `render.yaml` ตั้งค่า Web Service พร้อม Persistent Disk สำหรับฐานข้อมูล SQLite ไว้แล้ว โดย Render ต้องใช้แพ็กเกจที่รองรับ Persistent Disk ซึ่งเป็นแพ็กเกจแบบชำระเงิน

1. นำโครงการขึ้น GitHub โดยไม่อัปโหลด `node_modules` หรือไฟล์ใน `data/`
2. ใน Render เลือก **New > Blueprint** แล้วเชื่อมต่อ GitHub repository นี้
3. ตรวจสอบบริการ `my-cow-farm` และ Persistent Disk ขนาด 1 GB จากนั้นยืนยันการสร้างและรอ Deploy
4. เปิด URL ที่ Render แสดงหลัง Deploy เสร็จ

ฐานข้อมูลบัญชีและเซสชันจะอยู่ที่ `/var/data/farm.sqlite` และคงอยู่เมื่อมีการ Deploy หรือรีสตาร์ตตามปกติ ห้ามลบ Persistent Disk หรือสร้าง Disk ใหม่ทับของเดิมหากต้องการเก็บข้อมูลไว้

ข้อมูลฟาร์ม เช่น วัว อาหาร และรายการต่าง ๆ ยังเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคนตามระบบปัจจุบัน การนำเว็บขึ้น Render ไม่ได้ทำให้ข้อมูลเหล่านี้ซิงก์ระหว่างผู้ใช้หรืออุปกรณ์

## วันที่และยอดรวม

กรอกวันที่ด้วยปี พ.ศ. ในรูปแบบ `วว/ดด/พ.ศ.` เช่น `15/10/2569` วันที่ในประวัติและรายงานจะแสดงเป็น พ.ศ. เช่นกัน ส่วนยอดสุทธิท้ายตารางและไฟล์ Excel จะสรุปจำนวนและมูลค่ารวม โดยแยกหน่วยอาหารก่อนรวมปริมาณ

หน้าแดชบอร์ดสรุปข้อมูลจากรายการจริงของฟาร์ม และเลือกดูกราฟกำไรรายสัปดาห์ย้อนหลังได้ 4, 8 หรือ 12 สัปดาห์ ใช้ภาพ `พื้นหลัง.png` เป็นพื้นหลังทุกหน้าหลังเข้าสู่ระบบ ใช้ภาพ `ทุ่งฟาร์มแสนละมุนกับเจ้าวัวน้อย.png` ในแบนเนอร์ และใช้ `รูปหน้าปก.jpg` ที่หน้าเข้าสู่ระบบ ข้อความสภาพอากาศบนแบนเนอร์เป็นข้อมูลตัวอย่าง ไม่ใช่พยากรณ์อากาศแบบเรียลไทม์
